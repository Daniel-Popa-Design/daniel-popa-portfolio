# Daniel Popa — Portfolio

Portfolio website built with React and Vite.

## Local development

```sh
npm ci
npm run dev
```

Create a production build with `npm run build`.

## GitHub Pages

The site deploys automatically to
https://daniel-popa-design.github.io/daniel-popa-portfolio/ when changes are
pushed to `main`. In the repository settings, open **Pages** and set the
publishing source to **GitHub Actions**.
